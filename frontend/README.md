# More by Prinal: frontend

This folder contains the React front end for the More by Prinal storefront (Create React App,
Redux Toolkit, React Router and Tailwind CSS). It is a front-end only site: products are sample
data, the cart is kept in memory, and there is no checkout, backend or API.

See the [root README](../README.md) for features, project structure, setup and deployment.

## Commands

Run these inside `frontend/`:

```bash
npm install
npm start       # dev server at http://localhost:3000/morebyprinal/
npm run build   # production build in build/
npm test        # Jest test runner (react-scripts)
```
